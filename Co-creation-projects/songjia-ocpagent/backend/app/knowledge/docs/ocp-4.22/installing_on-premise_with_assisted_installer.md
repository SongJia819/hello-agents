## Installing OpenShift Container Platform on-premise with the Assisted Installer

Red Hat OpenShift Documentation Team

[Legal Notice](#idm140200004519776)

**Abstract**

This document describes how to install OpenShift Container Platform on-premise with the Assisted Installer.

---

## [Chapter 1. Installing an on-premise cluster using the Assisted Installer](#installing-on-prem-assisted) Copy linkLink copied to clipboard!

You can install OpenShift Container Platform on on-premise hardware or on-premise VMs by using the Assisted Installer for OpenShift Container Platform.

The Assisted Installer is a user-friendly installation solution offered on the Hybrid Cloud Console. The Assisted Installer reduces installation complexity, enabling users to deploy and configure OpenShift Container Platform clusters with minimal manual intervention.

For access to the Assisted Installer user interface and documentation, see *Additional resources*.
